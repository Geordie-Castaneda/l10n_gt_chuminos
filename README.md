# l10n_gt_chuminos
Gestión integral de operaciones de transporte: empleados, pilotos, contactos, flotilla, servicios y pagos.

El formulario público `/flotilla/solicitud` registra vehículos y sus conductores. Permite adjuntar hasta cinco fotos JPG, PNG o WebP; las imágenes se publican en el tracking del vehículo en Flotilla.
